2026-10-23。原谱 PDF 与重排辅助谱均已采用 `below-first-v1`：**下方 → 上方 → 右侧 → 左侧 → 待人工放置**。没有增加依赖，也没有更换识谱引擎。

后续已将默认字号改为自适应，在每个方向内按和弦整组逐档缩小，最低 3 pt；显式固定字号保留。下面的 10 pt 统计为当时的基线，最新对比见 [自适应字号验证](adaptive-font-sizing.md)。

## 布局规则

- 按优先级穷举当前区域的可接受位置，再尝试下一方向；在所属谱表下方尽量保持横向对齐，不让更近的上方空白抢先。
- 原谱复用已有二值墨迹掩码与积分图、实际字体包围盒（含变化音、八度点）、页面边界与标注碰撞检查。重排谱使用新的 SVG 图形包围盒，不混用原 PDF 坐标。
- 利用现有谱表几何和相邻谱表间的中线限定归属区域。横向偏移还需满足同一谱表音符列的邻近约束，替换旧的二维最近符头限制。竖向搜索最多延伸约 7 个谱线间距，左右最多约 2 个；这不是在整页任意找空白。
- 和弦按源符头的高低顺序组成一列，整体选方向和空白；整组放不下时保留待放置，不拆散到不同角落。
- 原谱先预留已保存的手动标注，自动布局避让它们；隐藏项不占位。手动位置仍需满足墨迹、页面和碰撞检查，不会被自动平移。
- 默认黑色 10pt，不为提高放置率自动缩小。重排固定字号按 210 mm 页面宽度与 SVG viewBox 换算；显式“自动字号”继续随符头大小调整，用户手动样式保留。

布局偏好不参与音高识别、八度线恢复或音符身份匹配；原严格校验保持启用。本次没有新增 OpenCV 处理。当前原谱“不可接受”的下方位置也包括跨入其他谱表、归属不清、超过搜索范围等情况，而不只是墨迹覆盖。
