2. 固定 Audiveris 版本，用无 GUI 批处理识别该页，保留日志、.omr、MusicXML。
3. 检查 .omr 的实际结构，提取符头边界与谱表；验证原谱坐标是否需要逆变换。
4. 优先查证 MusicXML 与原符头 ID 的关联；若不能关联，说明采用的替代方案及其限制，禁止无证据按顺序拼接。

6. 产出可检查 JSON、标注预览与 PDF；验证缩放和图像 / PDF 一致性。
7. 人工抽查高低谱表、和弦与八度；如无完整 ground truth，仅报告抽查，不报告全页准确率。
8. 写 P0 报告：通过项、失败项、覆盖范围、下一步。

验收：一个命令能复跑；原底图没有被重排；每个导出数字能追踪至符头与音高来源；未解决的识别 / 关联 / 碰撞显示为待校对。若首个样本只验证到部分链路，阶段保持部分通过。

交付位置：scripts/poc/（复跑脚本）、samples/（来源说明）、output/（可再生结果）、docs/poc-report.md（证据）。工具下载放 .tools/，不纳入源码。
