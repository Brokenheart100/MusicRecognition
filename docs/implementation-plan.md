## P0：一页真实钢琴谱原谱标注可行性

2026-10-21 状态：**部分通过**。原扫描谱 393 / 395 个自动放置；新增真实矢量 PDF《小步舞曲》，完整页与裁剪页分别识别，均为 200 / 201 个自动放置。四个旋转方向、带小数起点的裁剪及非零 MediaBox 起点共 9 个坐标 / 导出案例已建立并执行。标注统一黑色；原绘图指令与页面几何保留。待放置音符、完整语义正确率、多页、内容内部任意旋转等仍未验收。详见 [P0 报告](poc-report.md)。

1. 记录样谱出处、许可说明、哈希与选页原因；保留未经标注的输入。
2. 固定 Audiveris 版本，用无 GUI 批处理识别该页，保留日志、.omr、MusicXML。
3. 检查 .omr 的实际结构，提取符头边界与谱表；验证原谱坐标是否需要逆变换。
4. 优先查证 MusicXML 与原符头 ID 的关联；若不能关联，说明采用的替代方案及其限制，禁止无证据按顺序拼接。
5. 生成固定 C 音高提示（数字、变化音、八度点），布局避让后叠加原页面。
6. 产出可检查 JSON、标注预览与 PDF；验证缩放和图像 / PDF 一致性。
7. 人工抽查高低谱表、和弦与八度；如无完整 ground truth，仅报告抽查，不报告全页准确率。
8. 写 P0 报告：通过项、失败项、覆盖范围、下一步。

验收：一个命令能复跑；原底图没有被重排；每个导出数字能追踪至符头与音高来源；未解决的识别 / 关联 / 碰撞显示为待校对。若首个样本只验证到部分链路，阶段保持部分通过。

交付位置：scripts/runtime/（复跑脚本）、samples/（来源说明）、output/（可再生结果）、docs/poc-report.md（证据）。工具下载放 .tools/，不纳入源码。
