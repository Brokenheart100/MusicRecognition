# 工作台快捷键

2026-10-24。复用 VueUse `onKeyStroke` 和现有 Pinia 草稿/撤销历史，无新增依赖。

Windows 使用 Ctrl，macOS 使用 ⌘。按 `Ctrl / ⌘ K` 或 `?` 打开工作台使用指南，可以查看完整列表。

| 操作 | 快捷键 | 范围 |
| --- | --- | --- |
| 导入乐谱 | Ctrl / ⌘ O | 无输入焦点及弹窗时 |
| 保存修改 | Ctrl / ⌘ S | 输入框中也可使用；沿用可编辑/修订冲突检查 |
| 导出本页 PDF | Ctrl / ⌘ Shift E | 原谱视图、已保存且导出就绪的当前页 |
| 全选音符 | Ctrl / ⌘ A | 原谱视图，当前页和当前谱表/声部筛选范围 |
| 取消选择/放置 | Esc | 原谱视图，同时清除框选集合与放置状态 |
| 撤销 | Ctrl / ⌘ Z | 原谱草稿；输入框保留原生撤销 |
| 重做 | Ctrl Y、Ctrl / ⌘ Shift Z | 原谱草稿 |
| 下一个/上一个音符 | J / K | 当前筛选范围；无选择时分别从首个/末个开始 |
| 微调标注 | 方向键 | 原谱选中标注，支持整组移动 |
| 快速微调 | Shift + 方向键 | 每次 10 个识谱像素 |
| 隐藏/显示标注 | Delete / Backspace | 选中集合一次处理、一步撤销；混合状态先全部隐藏 |
| 下一个待放置音符 | N | 原谱视图 |
| 进入放置模式 | P | 原谱视图，有选择且可编辑；随后点击留白 |
| 放大/缩小 | + 或 = / − | 谱面缩放，每档 25%，范围 50–200% |
| 恢复大小 | 0 | 谱面恢复 100% |
| 上一页/下一页 | [ / ] | 多页 PDF；沿用草稿保留与切页提示 |
| 显示/隐藏简谱标注 | L | 原谱和重排辅助谱 |
| 校对面板开关 | I | 原谱视图 |
| 乐谱库开关 | B | 桌面收起/展开侧栏，窄屏打开/关闭乐谱库 |
| 使用指南开关 | Ctrl / ⌘ K | 输入框中也可使用 |
| 打开使用指南 | ? | 无输入焦点及弹窗时 |

## 输入与边界

- 输入框、可编辑文本、下拉菜单、菜单及弹窗保留自己的键盘行为。输入框中只额外保留保存和帮助组合键；打开的弹窗/菜单会阻止保存触发谱面动作。
- 中文输入组合期间不触发快捷键；长按不会反复切换隐藏、开关面板或重复保存。方向键和缩放允许连续操作。
- 未声明的 Ctrl / ⌘ 组合键仍交给浏览器。例如 Ctrl+J 不会被误判为 J 切换音符；浏览器原生缩放、刷新、打印快捷键不接管。
- 历史版本仍不能修改。导出快捷键复用当前页下载逻辑，不会替代整份 PDF 的合并和下载。
