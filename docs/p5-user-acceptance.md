# 初学者与教师使用验收

状态：待真实参与者执行。自动检查不能代替读谱、弹奏或纸张上的阅读判断。

## 测试准备

选择一位初学者与一位钢琴教师，各自记录使用设备、浏览器、显示缩放、打印机和纸型。样例包括：简单钢琴谱原谱叠加、含密集和弦的谱页、两张 Orange 截图的拼谱草稿。先保留未经标注的原谱供对照。

Orange 当前有第 5、6 小节时值疑点和八度线漏识别，须由教师校对后再用于练习；此次验收不能将已知错误草稿当作准确答案。

## 验收任务

| 执行者 | 任务 | 通过依据 |
| --- | --- | --- |
| 初学者 | 上传 PDF，观察排队、识别、导出状态 | 能判断任务正在运行、失败或可下载，并找到对应文件名/页码 |
| 初学者 | 对照 20 个单音与 10 个和弦的原谱数字 | 能指出每个数字所属音符；上下方、旁边回退不会造成归属混淆 |
| 初学者 | 调整字号/颜色，框选移动多个标注，撤销/重做 | 能完成操作，保存后刷新不丢修订，PDF 与选择的保存版本一致 |
| 初学者 | 将两张截图排序、框选、去除重叠小节 | 理解局部小节范围，能预览并下载 MusicXML，知道草稿仍需校对 |
| 教师 | 比较八度、谱号变化、和弦、变化音、跨谱表 | 逐项登记错音、漏音与记号问题，给出可复核的位置；不报告没有真值分母的准确率 |
| 双方 | 按实际 A4 纸型打印，不使用“适合页宽”掩盖字号问题 | 数字清晰、线条不被覆盖、页边不截断；记录过小/过密的具体小节 |
| 双方 | 手机上打开工作台、放大、滚动、回到保存版本 | 主要按钮可操作，内部谱面可滚动，页面无横向溢出；实际 Safari 单独记录 |
| 运维 | 提供失败任务 ID，由日志定位文件名和页面 | 普通用户看不到服务器路径和原始堆栈；管理人员能检索具体原因 |
