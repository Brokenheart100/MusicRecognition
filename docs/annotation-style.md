# 标注字号与颜色

更新：2026-10-22。

## 使用方式

打开乐谱后，在右侧「校对与标注 → 标注样式」选择字号与颜色，再点击「保存修改」。移动端通过「切换校对面板」打开相同设置。

- 默认：自动字号（随谱线间距）、黑色 `#000000`，保留既有标注效果。
- 字号：自动，或 3、4、5、6、7、8、10、12、16 pt；后端接受 3–16 pt。
- 颜色：黑、灰、蓝、红、绿预设，以及 Nuxt UI 取色器和六位 Hex 输入。
- 设置作用于当前页的全部数字、升降号与八度点，随修订保存；支持草稿恢复、撤销和重做。历史修订只读。
- 未保存时即时预览字形大小和颜色；保存后后端重新进行留白布局。字号增大可能增加待手动放置的标注，不会强行覆盖原谱。
- 多页 PDF 按每页选定修订合并，保留各页的字号与颜色。

## 实现与兼容性

`AnnotationStyle` 属于领域对象，保存于 `ScoreSnapshot` 的修订 JSON；不需要数据库表结构变更。旧修订缺省时按自动字号、黑色读取。字号/颜色通过 OpenAPI 生成 hey-api SDK、类型与 Zod 校验，前端未维护第二份接口类型。

字号单位是 PDF point（1/72 英寸）。渲染器根据原页坐标变换转换到识谱像素，并取最近整数像素；PDF 原件的 216 DPI 样本中 8 pt 对应 24 px。图片按原有 A4 宽度导出策略换算，可能产生小于半个源像素的字号取整误差。

浏览器继续使用后端提供的字形轮廓。草稿阶段保持原位置，保存后使用后端返回的完整布局、留白检测和八度点几何。颜色不影响识谱结果；纯样式修改只产生新导出修订，不重复识谱。
